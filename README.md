# Task Manager

A responsive task management web application built with HTML, CSS, JavaScript, and Bootstrap 5.

## Overview

Task Manager helps users organize daily tasks, track completion progress, and manage deadlines through a simple, interactive interface.

## Features

- Create, edit, and delete tasks
- Mark tasks as completed
- Set due dates and priority levels
- Organize tasks by category: Study, Work, Personal, and Other
- Search tasks by name
- Filter tasks by completion status
- Sort tasks by priority, due date, or creation order
- Track total, completed, remaining, and overdue tasks
- View overall progress and progress by priority
- Save tasks locally using browser localStorage
- Switch between light and dark mode
- Export and import tasks using JSON files
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5.3.3
- Browser localStorage
- JSON for task import and export

## Getting Started

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern web browser.
4. Start adding and organizing your tasks.

An internet connection is required to load Bootstrap from the CDN used in this project.

## Data Storage

Tasks and the dark-mode preference are stored in the browser's localStorage. The application does not currently use a backend server or a remote database.

Use the JSON export feature to back up tasks or transfer them to another browser.
